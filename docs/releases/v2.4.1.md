# Wardryx 2.4.1

The `wardryx` image, `ghcr.io/taipanbox/wardryx`, is built on Go 1.27.3. Go 1.27.3 fixes GO-2026-6809, a vulnerability in `crypto/x509`, and the 2.4.0 image was built on Go 1.27.2. Nothing else changes in behaviour: no decision, approval, token or record format moves, no setting is added or removed, and no name `compat/1.0.json` freezes is removed or renamed.

## Changed since 2.4.0

- #126, `build: Go 1.27.3 for GO-2026-6809 in crypto/x509`. The `go.mod` toolchain, the Go version of CI and of the release workflow, and the Dockerfile's `GO_VERSION` move to 1.27.3, and the gate anchors that named the old pin move with them.

No other commit lies between the 2.4.0 tag and this release.

## Upgrade

Replace the 2.4.0 image with 2.4.1. No setting, stored state or wire format changes, so there is nothing to migrate. To roll back, run the 2.4.0 image again.

Whether a given deployment of 2.4.0 reached the affected `crypto/x509` code was not measured. This release makes the question moot by moving the toolchain, and it is the way to close GO-2026-6809 in the published image.
