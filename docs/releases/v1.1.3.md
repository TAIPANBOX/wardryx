# Wardryx 1.1.3

Money in a refusal reason prints without float noise. No decision changes,
`PolicyVersion` is untouched.

## Fixed (wardryx#76, invariant 22)

A computed amount, such as an estimate summed from priced parts, printed its
float64 noise into the reason an operator reads: "$0.0055000000000000005".
Amounts are now rounded to the micro-dollar, the unit money is counted in,
with trailing zeros dropped ("$0.0055"). Whole cents keep the two-decimal form
("$100.00"), sub-cent amounts print as themselves ("$0.0005"), and a nonzero
amount below a micro-dollar never prints as zero. Both copies of the formatter
changed together and a test holds them to each other (wardryx#75).
