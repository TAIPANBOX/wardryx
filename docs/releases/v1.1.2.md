## Fixed (wardryx#72, invariant 22)

An approval token minted for a sub-cent ceiling and presented for more said
"approved ceiling $0.00 exceeded by requested $0.00", which reads exactly like
a zero ceiling. The reason now prints both amounts as themselves ("approved
ceiling $0.0005 exceeded by requested $0.0016"), in the internal error and in
the `reason` a `/v1/decide` caller reads. Cent-and-above amounts print as
before. This was the third reason string with the defect; the first two were
fixed in 1.1.1. Two tests, each red first on 1.1.1, and a planted mutant (the
old `%.2f` back) caught by both.

## Upgrade

Nothing to change. The `reason` field's text is not part of the frozen wire
(`compat/1.0.json` freezes the field, not its wording).
