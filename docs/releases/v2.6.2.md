# wardryx v2.6.2

The service, its binaries and its image are built with Go 1.27.4, which fixes GO-2026-6859 in `net/http`. The v2.6.1 image was built with Go 1.27.3. No policy decision, event, route, setting or file format changes, and no name `compat/1.0.json` freezes is removed or renamed.

Tag: `v2.6.2`. The image is `ghcr.io/taipanbox/wardryx:v2.6.2`. There is no moving tag (no `latest`, no `main`).
